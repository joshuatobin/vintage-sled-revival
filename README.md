# Tobin's Ski-Doo Garage

Buildless static website. `dist/` is the published directory.

Includes two provisional vehicle profiles, a parts/inspection tracker, actual purchase totals, workshop notes, a photo archive, source manuals and supplier leads.

Edits persist in browser localStorage under `tobin-skidoo-garage-v1`. JSON export/import carries the full state, including user-added resized photos. CSV exports the currently filtered parts list. No cross-device synchronization is implied.

## Identification policy

The early chassis is unconfirmed; 1963 is a working hypothesis. Engine serial transcription 1308696 and the supplied year chart are research leads only. The later chassis is provisionally SE8 / 1968 Olympique 300 E, pending the actual plate photograph. Factory specifications describe original models, not verified installed hardware.

The earlier shopping list's 293 cc, 69 mm 300E piston, 40:1 oil ratio, straight SAE30 chaincase fluid, production ordinal, and fixed bogie quantity are not treated as verified instructions.
